# scoop-dotagents

Scoop bucket for [dotagents](https://github.com/soorya-u/dotagents) — a CLI to manage and template configuration files for AI agents.

## Install

```powershell
scoop bucket add dotagents https://github.com/soorya-u/scoop-dotagents
scoop install dotagents
```

## Update

```powershell
scoop update dotagents
```
